# SellPilot development phases

The full phase roadmap, acceptance criteria, and technical specifications are in the main phases document:

**[Phase 0–8 (full document)](../../Docs/Phase_0_1_2_3_4.md)**

That document includes:

- **Phase 0:** Planning & architecture (repository structure, system design, schema, API, multi-tenancy, standards)
- **Phase 1:** Backend foundation (auth, JWT, stores, RBAC)
- **Phase 2:** Ecommerce core (products, orders, customers, invoices, analytics)
- **Phase 3:** AWS cloud integration (RDS, S3, EC2, CloudWatch)
- **Phase 4:** Frontend dashboard (Next.js, dashboard UI)
- **Phase 5:** AI marketing studio
- **Phase 6:** Seller growth agent
- **Phase 7:** Automation engine
- **Phase 8:** CI/CD and production polish

Use the main document for implementation details, code samples, and checklists. This file exists so that the Phase 0 deliverable path `docs/phases/PHASES.md` is satisfied and so that links from other docs (e.g. CONTRIBUTING, README) have a single place under `docs/` that points to the roadmap.
